인쇄하면 A4 두 장으로 나와요. 내 손으로 다시 정리할 때의 뼈대로 쓰세요.

1. 개요

  • 정의: 현실 시스템의 시간에 따른 동작을 흉내 · 분석 도구(변경 예측) / 설계 도구(새 시스템)
  • 쓰지 말 것: 상식·공식으로 풀림, 직접 실험이 쉬움, 비용 > 이득, 자료·시간·인력 부족, 과대 기대
  • 단점: RIRO (Random in → Random out) → 통계 분석 필요
  • 분류: Stochastic/Deterministic · Static/Dynamic · Discrete/Continuous → DES = 확률·동적·이산
  • 구성요소: Structural(레이아웃) · Operating(기계·작업자) · Flowing(부품)
  • Event = 순간, 상태 변화 / Activity = 시간이 걸리는 작업
  • Verification = 제대로 만들었나 / Validation = 맞는 모델인가

단일 서버 손계산

시작 = max(도착, 앞 완료), 완료 = 시작 + 서비스, 대기 = 시작 − 도착

M/M/1

\(\rho = \lambda/\mu\), \(L_q = \rho^2/(1-\rho)\), \(T_q = L_q/\lambda\), \(W = T_q + 1/\mu\), \(L = \lambda W\)
예) λ=1/6, μ=1/3 → ρ=0.5, Lq=0.5, Tq=3분

12단계

문제 구성 → 목표·계획 → 개념화 → 자료 수집 → 모델 변환 → Verified? → Validated? → 실험 설계 → 실행·분석 → More runs? → 문서화 → 적용

3. 입력 모델링

  • 절차: 문서화 → 수집 계획 → 수집 → 그래프·통계 → 분포 가정 → 모수 추정 → 적합도 → 민감도
  • 독립성: 지연 산점도 x(i) vs x(i+1) 직선이면 상관 · 정상성: 시간 추세

  • 이산 자료에 연속분포 X · 자료 없으면 균등(min,max)/삼각 · 경험분포는 범위 밖 값 없음

LCG

\(R_{i+1} = (aR_i + c) \bmod m\), \(U = R/m\). 완전주기 ⇔ ① gcd(c,m)=1 ② m 의 모든 소인수 | a−1 ③ 4|m ⇒ 4|a−1
m=8,a=5,c=1,R0=5: 2,3,0,1,6,7,4,5 (주기 8) · c=2: 3,1,7,5 (주기 4)

변량 생성

  • 역변환: \(X = F^{-1}(U)\) · 지수 \(X = -\frac1\lambda\ln(1-U)\)
  • 이산: \(U \le F(x_i)\) 인 첫 \(x_i\)
  • 채택-기각: \(g \ge f\), \(c=\int g\), \(h = g/c\); \(W\sim h\), \(U\cdot g(W) \le f(W)\) 이면 채택. 채택률 1/c. 예) \(f=\frac34(1-x^2)\): g=3/4, c=3/2
  • 그 밖에 합성곱(지수 k개 합 = 얼랑), 혼합
  • Plant Sim: z_uniform(스트림, a, b) — 시드 = 스트림 시작점

4. 출력 분석

  • Within vs Across replication · 관측 \(\bar T = \frac1n\sum T_i\) · 시간 \(\bar L = \frac{\sum q_k v_k}{t_n - t_0}\)
  • Ex I: Tq = 18/5 = 3.6, Lq = 18/15 = 1.2 · Ex II: Tq = 39/8 = 4.875, Lq = 39/25 = 1.56
  • Finite(은행·주문 100개) vs Infinite(24h 공장·응급실) → 워밍업으로 초기화 편향 제거
  • CI: \(\bar X \pm t_{1-\alpha/2,n-1} S/\sqrt n\) · 반폭 비율법 \(n \approx n_0(h_0/\epsilon)^2\)
  • 두 시스템: \(\hat D \pm t_{\hat\nu}\sqrt{S_1^2/n_1 + S_2^2/n_2}\), 0 포함 → 차이 단정 불가 · p < α → H0 기각
  • 최적화: 완전열거 10×10=100 (10분 16초) vs GA (3분 6초, 같은 해) · statAvgLifeSpan 은 Minimum
