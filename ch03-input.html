P-P 플롯 · Q-Q 플롯 손으로 그리기

P-P plot

① 정렬 \(x_{(1)} \le \dots \le x_{(n)}\) ② 경험 CDF \(\tilde F_n(x_{(i)}) = \frac{i-0.5}{n}\) ③ 가정 분포 CDF \(\hat F(x_{(i)})\) ④ \(\hat F(x_{(i)})\) vs \(\tilde F_n(x_{(i)})\) 를 그림. 확률 vs 확률 → 분포 가운데가 잘 보임.

Q-Q plot

① 정렬 ② \(q_i = \frac{i-0.5}{n}\) ③ 가정 분포의 역CDF \(x_{q_i} = \hat F^{-1}(q_i)\) ④ \(x_{q_i}\) vs \(x_{(i)}\). 값 vs 값 → 꼬리가 잘 보임.

둘 다 직선(대각선)에 가까우면 가정한 분포가 잘 맞는다는 뜻.

입력 모델링에서 기억할 것

  • 이산 자료에 연속분포를 피팅하지 말 것
  • 표준 분포가 좋지만, 안 맞으면 자료를 그대로 뽑는 경험분포도 가능 — 단 관측 범위 밖 값은 절대 안 나옴
  • 자료에 의존성·비정상성(시간대별 변화)이 있으면 특별한 기법 필요

  • 피팅 소프트웨어 결과가 내 판단을 대신하게 두지 말 것
PART 2

난수 만들기

선형합동생성기 (LCG)

시뮬레이션의 난수는 사실 결정적인 수열이에요(의사난수, pseudo-random). 진짜 U(0,1) 과 통계적 성질이 같으면 충분.

\[ R_{i+1} = (a R_i + c) \bmod m, \qquad U_i = \frac{R_i}{m} \]

\(R_0\) = 시드(seed), \(a\) = 곱수(multiplier), \(c\) = 증분(increment), \(m\) = 모듈러스. 바라는 성질: 빠름 · U(0,1)에 가까움 · 주기가 길 것 · 0이나 상수로 퇴화하지 않음 · 같은 수열 재현 가능 · 부분수열(스트림) 선택 가능.

완전주기 정리 (Full period, 주기 = m)

다음 세 조건이 모두 성립할 때만:

① \(c\) 와 \(m\) 의 공약수는 1뿐   ② \(m\) 을 나누는 모든 소수 \(q\) 가 \(a-1\) 을 나눔   ③ 4가 \(m\) 을 나누면 4가 \(a-1\) 도 나눔

연습 4LCG 손계산 (강의 예제 1·2)

\(m=8, a=5, c=1, R_0=5\). 처음 네 개를 구하세요.

풀이
\(R_1 = (5·5+1) \bmod 8 = 26 \bmod 8 = 2\) → 0.25. \(R_2 = 11 \bmod 8 = 3\), \(R_3 = 16 \bmod 8 = 0\), \(R_4 = 1\), 이어서 6, 7, 4, 5, 2 … — 0~7 이 한 번씩 다 나오고 반복 → 주기 8 (완전주기). 정리: c=1 과 8 은 서로소 ✓, 8 을 나누는 소수 2 가 a−1=4 를 나눔 ✓, 4|8 이고 4|4 ✓.

\(m=8, a=5, c=2, R_0=5\) 는 완전주기를 가질까? 깨지는 조건은?

LCG 실험기

난수 스트림과 시드 (Plant Simulation)

  • 시드는 주기 안의 시작 위치. 서로 다른 시드 = 서로 다른 스트림 → 도착용·서비스용처럼 용도별로 독립된 난수를 쓸 수 있음
  • 전체 시뮬레이션 시드: EventController 설정
  • 함수용 시드: 메뉴 Random Number Seed Values 표 — z_uniform, z_normal 등에만 적용. 예: z_uniform(3, 1, 10) = 스트림 3으로 1~10 균등난수
  • 같은 시드 → 같은 결과 재현 (디버깅, 대안 비교 시 공통난수)

난수 → 원하는 분포: 역변환법

방법 4가지: 역변환(Inverse CDF), 합성곱(Convolution — 예: 지수 k개 합 = 얼랑), 채택-기각(Acceptance/Rejection), 혼합(Composition).

역변환 알고리즘

1. \(U \sim U(0,1)\) 생성   2. \(X = F^{-1}(U)\) 반환. (근거: \(X \sim F\) 이면 \(F(X) \sim U(0,1)\))

지수분포 (율 \(\lambda\), 평균 \(1/\lambda\)): \(F(x) = 1 - e^{-\lambda x}\) → \(U = 1 - e^{-\lambda X}\) → \[ X = -\frac{1}{\lambda}\ln(1-U) \]

이산 역변환: CDF 표를 위에서부터 훑어 \(U \le F(x_i)\) 인 첫 \(x_i\) 반환.

풀이

U 를 직접 굴려 보기

왼쪽(U)은 평평한데 오른쪽(X = −m·ln(1−U))은 지수 모양. 같은 난수를 "모양만" 바꾼 것.

채택-기각법 (Acceptance-Rejection)

\(F^{-1}\) 을 구하기 어려울 때. 원하는 밀도 \(f(x)\) 를 위에서 덮는 majorizing 함수 \(g(x) \ge f(x)\) 를 잡고, \(c = \int g\), \(h(x) = g(x)/c\) (뽑기 쉬운 분포).

  1. \(W \sim h\) 생성
  2. \(U \sim U(0,1)\) 생성
  3. \(U \cdot g(W) \le f(W)\) 이면 \(X = W\) 채택, 아니면 버리고 1로

예제: \(f(x) = \frac34(1-x^2)\), \(-1 \le x \le 1\). 최댓값 \(\frac34\) (x=0) → \(g(x) = \frac34\), \(c = \int_{-1}^{1}\frac34 dx = \frac32\), \(h(x) = \frac12\) = U(−1, 1). 알고리즘: \(W = -1 + 2U_1\), \(U_2\) 생성, \(\frac34 U_2 \le \frac34(1-W^2)\) 이면 채택. 채택 확률 = \(1/c = 2/3\).
