Method 와 편집기

Method 객체 · 편집기

Method(함수)는 항상 본문(body)이 있어요. Information Flow 에서 Method 를 Frame 에 놓고 더블클릭하면 편집기가 열려요.

기능방법
줄 번호VIEW – DISPLAY LINE NUMBERS
선택더블클릭 = 단어, 세 번 클릭 = 한 줄, Ctrl + A = 전체
복사·붙여넣기·취소Ctrl + C / Ctrl + V / Ctrl + Z (버전 9 까지는 오른쪽 클릭 복사 안 됨). 끌어서 옮기기도 가능
책갈피텍스트 선택 후 책갈피 버튼 → 빨간색 표시, 빠른 이동
코드 자동완성후보가 하나면 하늘색으로 제안 → Ctrl + Space 로 수락. 객체 뒤에서 Ctrl + Space = 가능한 속성·메서드 목록
속성·메서드 정보객체 오른쪽 클릭 → Show Attributes and Methods

예약 이름 · 익명 식별자 · 경로

예약된 메서드 이름

  • Reset — EventController 에서 Reset 누를 때
  • Init — Init 누를 때 (시작 전 초기화)
  • EndSim — 종료 시각에 도달했을 때

익명 식별자

  • root — Frame 계층의 맨 위
  • self — 지금 객체(메서드 자신)
  • current — 지금 Frame
  • ? — 메서드를 부른 객체
  • @ — 메서드를 일으킨 MU
  • basis — 클래스 라이브러리

경로: 절대 경로는 클래스 라이브러리 루트부터 — .Models.Frame.workplace_1. 상대 경로는 메서드가 있는 Frame 안에서 — workplace_1.

-- EndSim
