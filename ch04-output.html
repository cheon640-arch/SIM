PART 1

통계 모으기

반복 (Replication)

Replication = 초기 조건에서 종료 조건까지 시스템이 진화하는 표본 경로 하나를 만드는 것.

Within-replication 통계

한 번의 반복 안에서 모은 값. 예: 이번 실행의 손님 100명 대기시간 평균.

Across-replication 통계

여러 반복의 결과를 가로질러 모은 값. 예: 반복 10번의 평균 대기시간 10개 → 평균·표준편차·신뢰구간.

한 반복 안의 관측값(1번 손님, 2번 손님…)은 서로 상관되어 있고 분포도 같지 않아서 바로 신뢰구간을 만들 수 없어요. 반면 반복마다의 평균은 서로 독립이고 같은 분포 → 고전 통계(t-분포)를 쓸 수 있어요.

관측(Observational) vs 시간 기반(Time-based) 자료

Observational — 빈도

지속되지 않는, 같은 무게의 값들의 나열. 개체가 어떤 상태에 들어간 시각과 나온 시각을 찍어 그 구간 길이를 기록. 예: 대기시간, 체류시간(리드타임).
\[ \bar T_q(n) = \frac{1}{n}\sum_{i=1}^{n} T_i, \quad T_i = D_i - A_i \]

Time-based — 지속시간

일정 시간 동안 유지되는 값, 그 시간만큼 가중. 보통 상태변수. 예: 대기열 길이, WIP, 가동 여부.
\[ \bar L_q(n) = \frac{\int_{t_0}^{t_n} q(t)\,dt}{t_n - t_0} = \frac{\sum_k q_k v_k}{t_n - t_0} \]

유한 · 무한 시간 범위

Finite horizon vs Infinite horizon

Finite (terminating)

끝나는 시각·조건이 분명. 예: 9시~17시 은행, 전력이 임계값에 닿을 때까지의 전투, 제품 100개 주문 생산.

Infinite (steady state)

뚜렷한 끝이 없고 장기(정상상태) 거동에 관심. 예: 공장의 정상상태 처리량, 24/7 응급실, 항상 켜진 통신 시스템.
연습 4분류

Finite horizon 분석: 독립 반복법과 반복 수

독립 반복법: 같은 초기 조건에서 서로 다른 난수로 여러 번 실행 → 반복 평균 \(X_1, \dots, X_n\) 이 독립. 신뢰구간:

\[ \bar X \pm t_{1-\alpha/2,\,n-1}\,\frac{S}{\sqrt n}, \qquad h = t_{1-\alpha/2,\,n-1}\frac{S}{\sqrt n}\ \ (\text{반폭, half-width}) \]
t-분포 반복법

원하는 반폭 \(\epsilon\) 이 되는 가장 작은 \(n\): \(n \ge \left(\dfrac{t_{1-\alpha/2,\,n-1}\, S}{\epsilon}\right)^2\). t 가 n 에 따라 바뀌니 n 을 늘려 가며 확인.

반폭 비율법

예비 실행 \(n_0\) 번에서 반폭 \(h_0\) → \(n \approx n_0 \left(\dfrac{h_0}{\epsilon}\right)^2\) (올림).

Plant Sim: Manage Class Library → Tools 의 Sequential Sampler 에 반폭·신뢰수준을 주면 반복 수를 정해 줘요.

대안 비교와 최적화

두 시스템 비교 (분산 미지 · 서로 다름)

입력이 다르면 출력도 당연히 달라요. "다른가?"가 아니라 "어느 쪽이 나은가?"를 통계적으로 말하는 게 목표.

\[ \hat D = \bar X_1 - \bar X_2, \qquad \hat D \pm t_{1-\alpha/2,\,\hat\nu}\sqrt{\frac{S_1^2}{n_1} + \frac{S_2^2}{n_2}} \] \[ \hat\nu = \frac{\left(S_1^2/n_1 + S_2^2/n_2\right)^2}{\dfrac{(S_1^2/n_1)^2}{n_1 - 1} + \dfrac{(S_2^2/n_2)^2}{n_2 - 1}} \]
  • 구간이 0을 포함하지 않으면 차이가 통계적으로 유의 → 부호로 어느 쪽이 큰지 판단
  • 0을 포함하면 이 표본으로는 어느 쪽이 낫다고 말할 수 없음
  • 신뢰수준 \(1-\alpha\) (예: 95%) ↔ 유의수준 \(\alpha\) (0.05)
  • p-value = \(H_0\) 가 참일 때 관측한 것만큼 또는 더 극단적인 결과가 나올 확률. p < α 이면 \(H_0\) 기각
